# Bluetti PR30V2 (BLE → MQTT)

Аддон опрашивает станцию командой `bluetti-read` (пакет `bluetti-bt-lib`),
публикует все найденные поля в MQTT и создаёт сущности в Home Assistant
через MQTT Discovery. Управление — через `bluetti-write`.

## Установка

1. Скопируйте папку `bluetti_pr30v2` в каталог `/addons/` (Samba/SSH, раздел **addons**).
2. **Настройки → Аддоны → Магазин → ⋮ → Проверить обновления**, затем
   найдите аддон в разделе *Local add-ons* и установите.
3. Убедитесь, что установлен и запущен аддон **Mosquitto broker** и в HA включена интеграция MQTT.
4. Заполните настройки, запустите аддон.

## Важно

* Останавливайте другие клиенты, которые держат BLE-соединение с PR30V2
  (приложение Bluetti на телефоне, интеграция `hassio-bluetti-bt`, и т.п.) —
  станция принимает только одно подключение.
* Найти MAC можно командой `bluetti-scan` или в списке Bluetooth-устройств HA.

## Настройки

| Параметр | Описание |
|---|---|
| `mac` | MAC станции |
| `device_type` | Тип (`PR30V2`) |
| `encryption` | Передавать `-e True` (для PR30V2 нужно) |
| `poll_interval` | Период опроса, сек |
| `command_timeout` | Таймаут CLI-команды, сек |
| `mqtt_*` | Необязательно: вручную указать брокер; иначе берётся Mosquitto через Supervisor |
| `controls` | Список переключателей: имя, поле для `bluetti-write`, аргументы включения/выключения |

### Управление

Для каждого элемента `controls` создаётся `switch`, который выполняет:

```
bluetti-write -m <mac> -t <type> -e True <on_args|off_args> <field>
```

По умолчанию `on_args: "--on on"`, `off_args: "--off off"`, поля `ctrl_ac`, `ctrl_dc`.
Проверьте синтаксис вручную из консоли аддона/контейнера и при необходимости поправьте.

> ⚠️ В документации `bluetti-bt-lib` сказано, что запись на устройствах с
> шифрованием поддерживается не везде. PR30V2 использует шифрование, поэтому
> чтение должно работать, а запись нужно проверить на вашей станции.
